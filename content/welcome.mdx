Thanks for stopping by! This space is where I document engineering projects, experiments, and technical deep-dives.

## Tech Stack

This portfolio was built with modern web technologies focused on speed, aesthetics, and developer experience:

- **Framework**: [Next.js 14](https://nextjs.org/) App Router
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) & Radix UI primitives
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **AI Integration**: Custom AI chatbot streaming assistant
- **Writing**: Markdown & MDX with code syntax highlighting
